## Scope of this sweep

The evidence pass on Phase 0e, branch `core/lone-pair-angles`
([#7](https://github.com/altamashmomin/orbital-chemistry-fable/pull/7), commit `58a82a0`), after an
external review of sweep 02 found that the "measured" checks were circular (`REAL_ANGLES` derived from
the embedder's own `LONE_PAIR_ANGLES`), that a bare `CRC` tag did not establish the values, and that
keying by display slots (`O/2/1` for an oxygen that has two lone pairs) was a trap. What changed:

* `src/chem/references/measured.js` is a new, independent oracle: one row per measurement with
  molecule, CAS number, atoms, the figure as listed and its citation, copied by hand from the NIST
  CCCBDB experimental-geometry listings on 2026-10-27. The embedder never imports it. The table keeps
  its own literal numbers and names the oracle row each came from; 19 new `lp-table.*` checks fail if
  either side drifts.
* Values corrected to the cited measurements: NH₃ 107.3° → 106.7°, CH₃OH 108.5° → 108.9°, (CH₃)₂O
  111.7° → 111.2° (rₛ, 2003; the 1963 microwave 111.7° is recorded), ClF₃ 175.0° → 174.9°. Acids and
  esters now follow formic acid (106.3°) and methyl formate (114.8°), both on CCCBDB, instead of the
  uncited acetic acid / methyl acetate figures, which the citations keep as the class range. PH₃, H₂Se
  and SO₂ got sourced rows (the register used to quote them as fallback examples).
* `lonePairAngleTargets(atom, neighbourEls)` keys by the drawn lone-pair count plus `:sp2` for a
  planar centre with a p lone pair, and returns `basis: 'exemplar' | 'class' | 'fallback'` with the
  exemplar, so any display can say what an angle is; the conformance labels now read "follows the
  measured CH₃OH value (class approximation for alcohols)" instead of "the measured value".
* Register rows for class approximations, amines, the fallback, the methanethiol source discrepancy
  and the pinned reaction centres; the mechanism references state the pinned-centre convention.

Mechanism frames and the nine lone-pair-free explorer molecules remain bit-identical to `main`
(the compression code did not change; only its inputs did). The table below is the run on `58a82a0`.
